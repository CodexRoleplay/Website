# Codex RP

Site Next.js du serveur Codex RP : accueil, règlement, code pénal, FAQ, boutique et panel admin.

## Démarrage

```bash
npm install
npm run dev
```

Copiez `.env.example` vers `.env.local` et renseignez les variables Firebase / Tebex.

La configuration Firebase est documentée dans `docs/FIREBASE_SETUP.md`.
